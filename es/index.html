El fallo

Las correcciones desaparecen dentro del historial de chat.

Cada correccion util es un pequeno postmortem. Rulewright convierte esos momentos en instrucciones reutilizables antes de que la leccion se pierda en otra transcripcion.

Como funciona

De una sesion corregida a una regla de proyecto.

01

Lee la sesion

Empieza desde el thread de Codex o transcript donde el agente fue corregido.

02

Detecta la leccion

Clasifica senales de alcance, verificacion, comunicacion y perfiles de idioma localizados.

03

Propone el patch

Dirige una regla estrecha a AGENTS.md, CLAUDE.md, Cursor rules o Copilot instructions.

Ejemplos

Reglas basadas en correcciones reales.

Control de alcance

Cambiaste todo el layout. Solo pedi arreglar la edicion crop.

+ Fija el alcance solicitado mas pequeno antes de editar.
Verificacion

No digas que esta arreglado sin ejecutar el test.

+ Verifica el comportamiento reportado antes de declarar la correccion completa.
Perfiles de idioma

Si la correccion fue en espanol, la regla tambien deberia quedar en espanol.

+ Escribe la regla en el idioma detectado del usuario.

Instalar

Usalo donde tus agentes ya leen reglas.

Clona una vez y luego instala Rulewright en tu flujo de agente preferido.

Codex

npm run install:codex

Instala Rulewright como plugin personal de Codex y entrada de marketplace.

Claude Code

npm run install:claude

Copia la skill de Rulewright en tu carpeta de skills de Claude Code.

Cursor

npm run install:cursor -- /path/to/project

Agrega una regla de repositorio en .cursor/rules/rulewright.mdc.

GitHub Copilot

npm run install:copilot -- /path/to/project

Actualiza .github/copilot-instructions.md con un bloque de Rulewright.

Open source

No pierdas las correcciones que ya pagaste.

Rulewright es un prototipo open-source temprano para equipos que quieren mejorar el comportamiento de agentes con evidencia concreta de sesiones.
