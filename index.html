The failure mode

Corrections disappear inside chat history.

Every useful correction is a tiny postmortem. Rulewright turns those moments into reusable project instructions before the lesson fades into another session transcript.

How it works

From corrected session to project rule.

01

Read the session

Start from the Codex thread or transcript where the agent was corrected.

02

Detect the lesson

Classify scope, verification, communication, and localized language-profile signals.

03

Propose the patch

Route a narrow rule to AGENTS.md, CLAUDE.md, Cursor rules, or Copilot instructions.

Examples

Rules grounded in actual corrections.

Scope control

You changed the whole layout. I only asked for crop edit.

+ Lock the smallest requested scope before editing.
Verification

Do not say it is fixed without running the test.

+ Verify the reported behavior before claiming the fix is complete.

Install

Use it where your agents already read rules.

Clone once, then install Rulewright into your preferred agent workflow.

Codex

npm run install:codex

Installs Rulewright as a personal Codex plugin and marketplace entry.

Claude Code

npm run install:claude

Copies the Rulewright skill into your Claude Code skills folder.

Cursor

npm run install:cursor -- /path/to/project

Adds a repository rule at .cursor/rules/rulewright.mdc.

GitHub Copilot

npm run install:copilot -- /path/to/project

Updates .github/copilot-instructions.md with a Rulewright block.
