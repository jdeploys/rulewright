실패 패턴

교정은 채팅 기록 속에서 사라집니다.

쓸모 있는 교정은 작은 postmortem입니다. Rulewright는 그 순간을 세션 기록 속에서 사라지기 전에 재사용 가능한 프로젝트 지침으로 바꿉니다.

작동 방식

교정된 세션에서 프로젝트 규칙까지.

01

세션 읽기

에이전트가 교정받은 Codex thread 또는 transcript에서 시작합니다.

02

교훈 감지

범위, 검증, 커뮤니케이션, 로컬라이즈된 언어 프로필 신호를 분류합니다.

03

패치 제안

AGENTS.md, CLAUDE.md, Cursor rules, Copilot instructions에 들어갈 좁은 규칙을 라우팅합니다.

예시

실제 교정에서 나온 규칙.

범위 제어

전체 레이아웃을 바꾼 게 문제야. crop 편집만 고치라고 했어.

+ 수정 전에 요청된 가장 작은 범위를 고정한다.
검증

테스트도 안 돌리고 고쳤다고 말하지 마.

+ 완료라고 말하기 전에 보고된 동작을 검증한다.
언어 프로필

한국어로 교정했으면 규칙도 한국어로 남겨야지.

+ 감지한 사용자 언어로 규칙을 작성한다.

설치

에이전트가 이미 읽는 규칙 위치에서 쓰세요.

한 번 clone한 뒤 원하는 에이전트 워크플로에 Rulewright를 설치합니다.

Codex

npm run install:codex

Rulewright를 개인 Codex 플러그인과 marketplace 항목으로 설치합니다.

Claude Code

npm run install:claude

Rulewright skill을 Claude Code skills 폴더로 복사합니다.

Cursor

npm run install:cursor -- /path/to/project

.cursor/rules/rulewright.mdc에 repository rule을 추가합니다.

GitHub Copilot

npm run install:copilot -- /path/to/project

.github/copilot-instructions.md의 Rulewright 블록을 갱신합니다.

오픈소스

이미 비용을 치른 수정 사항을 잃어버리지 마세요.

Rulewright는 에이전트 행동을 실제 세션 증거로 개선하고 싶은 팀을 위한 초기 오픈소스 프로토타입입니다.
