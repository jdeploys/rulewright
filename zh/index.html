失败模式

纠正会消失在聊天记录里。

每一次有用的纠正都是一次小型复盘。Rulewright 会在教训被新的会话记录淹没之前，把它转成可复用的项目指令。

工作方式

从已纠正会话到项目规则。

01

读取会话

从代理被纠正的 Codex thread 或 transcript 开始。

02

检测教训

分类范围、验证、沟通和本地化语言配置相关信号。

03

提出补丁

把窄范围规则路由到 AGENTS.md、CLAUDE.md、Cursor rules 或 Copilot instructions。

示例

来自真实纠正的规则。

范围控制

问题是你改了整个布局。我只让你修 crop 编辑。

+ 编辑前先锁定最小请求范围。
验证

不要没跑测试就说已经修好了。

+ 声称完成前验证用户报告的行为。
简洁回复

太长了。只告诉我改了什么、验证了什么。

+ 先说明结果，再补充建立信任所需的证据。

安装

在代理已经读取规则的地方使用。

clone 一次，然后把 Rulewright 安装到你偏好的代理工作流。

Codex

npm run install:codex

将 Rulewright 安装为个人 Codex 插件和 marketplace 条目。

Claude Code

npm run install:claude

把 Rulewright skill 复制到 Claude Code skills 文件夹。

Cursor

npm run install:cursor -- /path/to/project

在 .cursor/rules/rulewright.mdc 添加 repository rule。

GitHub Copilot

npm run install:copilot -- /path/to/project

更新 .github/copilot-instructions.md 中的 Rulewright block。

开源

不要丢掉你已经付出代价得到的修复。

Rulewright 是一个早期开源原型，面向希望用具体会话证据改进代理行为的团队。
